# Finessers AI

Don't stress it. Finesse it.

Early-stage student study workspace using React and Vite.

## Run

Install dependencies with `npm install`, then start with `npm run dev`.

## Included

- Responsive landing page
- Features page
- Interactive workspace for adding temporary classes
- AI chat interface preview (no real AI connection)

## Next

- Supabase authentication and secure database
- Backend AI API endpoint
- Study material uploads and quizzes
- User-approved computer-use workflows

This is a frontend prototype; there are no live AI answers or persistent accounts yet.
