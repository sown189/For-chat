# Finessers local operator
Version 0.2 — Chrome 116 or newer. Extract the ZIP, open chrome://extensions in desktop Chrome, enable Developer mode, select Load unpacked, and choose the finessers-chrome directory. Open a public webpage, click the extension icon, Connect tab, preview a control and Execute. Open Side Panel to keep Finessers beside the website. Use the toolbar icon to regrant access after cross-origin navigation. Stop clears pending actions; an already dispatched click cannot be undone. The extension uses activeTab and scripting only. Screenshots remain local. It is a manual approval tool with local command matching, not autonomous AI. It does not use Gemini or read cookies or passwords. Do not use it for autonomous graded submissions. Close or stop to end the connection. To test without a real account, use the practice page linked on the Finessers preview site.
